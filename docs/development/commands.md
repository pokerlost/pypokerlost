# Development commands

Use the locked `uv` environment and the repository Makefile for formatting, static analysis,
generation checks, and distribution builds.

## Prepare the environment

```bash
uv lock
uv lock --check
uv sync --locked --all-groups
```

`make lock` updates `uv.lock`, `make lock-check` verifies it without changes, and `make sync`
installs every locked dependency group.

## Regular gate

```bash
make check
```

The regular gate is non-mutating. It runs the lock check, Ruff format check, Ruff lint, strict
mypy, bytecode compilation, generator version check, and canonical public-import check.

Run individual stages when diagnosing a failure:

```bash
make format-check
make lint
make typecheck
make compile
make generator-check
make import-check
```

## Formatting

```bash
make format
```

`make format` applies safe Ruff fixes and formatting. Review its diff before continuing.

## Full gate

```bash
make pre-commit
make check-full
```

`make pre-commit` runs all configured hooks against every tracked file. `make check-full` adds the
wheel/source build and complete pre-commit pass to the regular gate.

## Direct commands

The equivalent focused commands use the locked project environment:

```bash
uv run --locked ruff format --check .
uv run --locked ruff check .
uv run --locked mypy
uv run --locked python -m compileall -q pypokerlost scripts
uv run --locked python scripts/generate_methods.py --version
uv build
git diff --check
```

## Generator contract check

When an OpenAPI JSON contract is available, verify its generated output without writing:

```bash
uv run --locked python scripts/generate_methods.py file path/to/openapi.json \
  --output pypokerlost \
  --check
```

The core repository contains no concrete generated service package. Cross-repository validation
uses a disposable service generated by `serviceTemplate`; see [Generator usage](../generator/usage.md).

## Docker artifact build

Export the build-only Docker target into a local `dist/` directory:

```bash
docker buildx build \
  --target artifacts \
  --output type=local,dest=dist \
  .
```
